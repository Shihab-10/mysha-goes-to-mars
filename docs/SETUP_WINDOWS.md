# Windows Setup Guide

## Requirements

- Windows 10 or 11
- VS Code
- Git
- Node.js LTS (recommended 20+)

## Steps

1. Open VS Code.
2. Use File > Open Folder and select the project folder: `NASA Space Game`.
3. Open a terminal in VS Code.
4. Run:
   npm install
5. Start the app with:
   npm run dev
6. Visit the local URL shown in the terminal.

## Useful validation steps

- `npm run typecheck`
- `npm run lint`
- `npm run test`
- `npm run build`

## Recommended extensions

- ESLint
- Prettier
- TypeScript and JavaScript Language Features

## Local git status

Git can be initialized locally if the folder is not already a repository. This project does not push or commit until the user explicitly requests it.
